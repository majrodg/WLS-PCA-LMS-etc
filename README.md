## Project Structure

This repository is organized for Statistical Analysis Plan (SAP) work with the following structure:

```
.
├── data/               # Data files
│   ├── raw/           # Original, unmodified data
│   └── processed/     # Cleaned and processed data
├── analysis/          # Analysis code and models
│   ├── scripts/       # Analysis scripts (R, Python, SAS, etc.)
│   └── models/        # Statistical models and outputs
├── documentation/     # Project documentation
│   ├── sap/          # Statistical Analysis Plan documents
│   └── reports/       # Analysis reports and study documentation
└── output/            # Analysis outputs
    ├── figures/       # Generated plots and figures
    └── tables/        # Generated tables and summary statistics
```

## Getting Started

1. Place raw data files in `data/raw/`
2. Store analysis scripts in `analysis/scripts/`
3. Document your Statistical Analysis Plan in `documentation/sap/`
4. Generated outputs will be saved in `output/`
